# Event Subscriptions

Pass `on_chunk` and/or `on_event` to `client.trigger()`. Both callbacks receive updates from the main agent and its subagents. Supply them on each trigger you want to observe.

## Available Events

| Callback     | Event                    | When it fires                                     | Useful fields                                                                               |
| ------------ | ------------------------ | ------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `on_chunk` | `AgentResponseChunk`   | Streamed text and model/runner completion updates | `text`, `invoked`, `finished`, `runner_id`, `parent_runner_id`                    |
| `on_event` | `AgentInvocationEvent` | After each completed model invocation             | `text`, `invocation_id`, `finished`, token usage, runner metadata                     |
| `on_event` | `ToolExecutionEvent`   | Before and after a client-side tool executes      | `name`, `arguments`, `status`, `result`, `error`, `tool_call_id`, `runner_id` |

For model events, `finished=True` means that runner has finished its task. `finished=False` means the model requested tools and may invoke again. On raw chunks, `invoked=True` marks a completed model invocation; ordinary text chunks have it set to `False`.

Tool status follows `started → succeeded` or `started → failed`. Successful events carry `result`; failed events carry `error`. Match these events using `tool_call_id`. For `SubagentOperator.trigger_subagent`, `succeeded` means dispatch succeeded; observe the subagent's model events for its actual completion.

`AgentInvocationEvent.text` combines the invocation's streamed text and may be empty for a tool-only response. Token usage fields are optional; handle `None`. Its `invocation_id` is generated by the SDK.

## Subscribe

```python
import asyncio

from dynamic_agent_client import (
    AgentEvent,
    AgentInvocationEvent,
    AgentResponseChunk,
    DynamicAgentClient,
    ToolExecutionEvent,
)
from dynamic_agent_client.service_handler import ServiceHandler


def on_chunk(chunk: AgentResponseChunk) -> None:
    """Print only the main agent's streamed text."""
    if chunk.parent_runner_id is None and chunk.text and not chunk.finished:
        print(chunk.text, end="", flush=True)


def on_event(event: AgentEvent) -> None:
    """Observe model usage and tool execution."""
    if isinstance(event, AgentInvocationEvent):
        print("\nModel:", event.runner_id, event.total_tokens, event.finished)
    elif isinstance(event, ToolExecutionEvent):
        print("\nTool:", event.name, event.status)
        if event.status == "succeeded":
            print("Result:", event.result)
        elif event.status == "failed":
            print("Error:", event.error)


async def main():
    """Subscribe while running a chat turn."""
    await DynamicAgentClient.connect("http://localhost:7777")
    client = await DynamicAgentClient.create(setting="Reply briefly in English.")
    answer = await client.trigger("Say hello.", on_chunk=on_chunk, on_event=on_event)
    await client.close()
    await ServiceHandler.stop()


asyncio.run(main())
```

Register an [operator](operator.md) before triggering to receive tool events when the model uses it. `trigger()` still returns the completed response in `answer`.

Callbacks must be synchronous (`def`) and quick; the SDK does not await them. Schedule asynchronous work separately. For model events and chunks, `parent_runner_id is None` identifies the main agent; a value identifies a subagent. `parent_tool_call_id` links a subagent to the parent tool call that dispatched it.
